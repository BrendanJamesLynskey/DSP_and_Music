### Also

- **[DDSP — Differentiable DSP](https://github.com/BrendanJamesLynskey/DDSP_Differentiable_DSP)** — additive + subtractive synthesis controlled by neural-style parameter curves, gradient visualisation, resynthesis presets.
- **[CORDIC](https://github.com/BrendanJamesLynskey/CORDIC)** — synthesisable SystemVerilog implementations of the CORDIC algorithm.
- **[Matrix Concepts in Digital Filters](https://github.com/BrendanJamesLynskey/Matrix_Concepts_Digital_Filters)** — state-space stability, Hermitian optimal taps and paraunitary filter banks, with a live pole explorer, eigenfilter bowl and breakable paraunitary rotation. Paired with **[Matrix Methods in Network Parameters](https://github.com/BrendanJamesLynskey/Matrix_Methods_Network_Parameters)** (S-, Z- and Y-parameters, mixed-mode, passivity, the Smith chart) and **[Equalisation in High-Speed Serial Links](https://github.com/BrendanJamesLynskey/SerDes_Equalisation)**, which applies both to one real 28 GBd backplane channel end to end. All three are listed under [Signal Processing Guides](SignalProcessingGuides.md#matrix-methods), along with **[Signal Integrity &amp; High-Speed Digital Design](https://github.com/BrendanJamesLynskey/Signal_Integrity)** — the eleven-deck series the same approach grew into.

# DSP & Music

A collection of browser-based projects exploring digital signal processing, synthesis, and music — interactive synthesizers, DSP theory guides, plugin examples, and machine-learning audio. Browse by area:

| Area | What's inside |
|------|---------------|
| **[Synthesizers](Synthesizers.md)** | Nine browser instruments — additive, FM, granular, physical modelling, modular, spectralist, a Byzantine-chant synth, the Phatty groovebox, and the ROLLER drum &amp; bass engine |
| **[Early Western Music](EarlyWesternMusic.md)** | Chant → Notre-Dame organum → troubadour song, voiced as it was historically performed (three apps) |
| **[Vocal Synthesis](VocalSynthesis.md)** | The history of singing-voice synthesis — mechanical to neural — with a live A/B explorer |
| **[Analysis & Effects](AnalysisAndEffects.md)** | Spectral analysers, phase vocoder, reverb / room acoustics, ambisonics, and more (eight tools) |
| **[Audio Plugins](AudioPlugins.md)** | A plugins hub, an in-depth JUCE tutorial, and seven example plugins (live browser demo + JUCE C++) |
| **[Signal Processing Guides](SignalProcessingGuides.md)** | Interactive visual guides to the transforms — STFT, wavelets, CQT, MDCT, MFCC, Laplace, Kramers–Kronig — plus the matrix methods behind filters and networks |
| **[Companions to J. O. Smith's textbooks](JOS_Companions.md)** | Browser-first companions to the five CCRMA online books |
| **[Neural / ML Audio Synthesis](NeuralAudioSynthesis.md)** | A twelve-part interactive series on the ML techniques that generate sound |

### Also

- **[DDSP — Differentiable DSP](https://github.com/BrendanJamesLynskey/DDSP_Differentiable_DSP)** — additive + subtractive synthesis controlled by neural-style parameter curves, gradient visualisation, resynthesis presets.
- **[CORDIC](https://github.com/BrendanJamesLynskey/CORDIC)** — synthesisable SystemVerilog implementations of the CORDIC algorithm.
- **[Matrix Concepts in Digital Filters](https://github.com/BrendanJamesLynskey/Matrix_Concepts_Digital_Filters)** — state-space stability, Hermitian optimal taps and paraunitary filter banks, with a live pole explorer, eigenfilter bowl and breakable paraunitary rotation. Paired with **[Matrix Methods in Network Parameters](https://github.com/BrendanJamesLynskey/Matrix_Methods_Network_Parameters)**, the continuous-time companion for RF and high-speed digital (S-, Z- and Y-parameters, passivity, the Smith chart). Both are listed under [Signal Processing Guides](SignalProcessingGuides.md#matrix-methods).
